# DarkLedger

> Тёмный реестр — локальный трекер активности для Windows.

## 🖤 О проекте

**Dark Ledger** — полностью локальный трекер активности для Windows 10/11.
Никаких серверов, аккаунтов и телеметрии — все данные хранятся только на твоём компьютере.

> _"Ledger помнит всё. Но никому не расскажет."_

## ✨ Возможности

- 📊 **Обзор** — Uptime, отслеженное время, топ приложений за период
- 📖 **Хроника** — все сессии с фильтрами и экспортом в CSV/TXT
- 🔥 **Аналитика** — Heatmap 24×7, индекс фокуса, сравнение недель
- 📔 **Дневник** — заметки по дням с календарём и поиском
- 📈 **Отчёты** — текстовые отчёты и экспорт всех данных в ZIP
- 🎯 **Цели** — лимиты на приложения и минимальный фокус
- 📌 **Трей** — сворачивание в системный трей
- 🔄 **Автообновление** — проверка новых версий через GitHub Releases

## 🖥️ Технологии

- .NET 8
- WPF
- Hardcodet.NotifyIcon.Wpf

## 📦 Установка

1. Скачай последний релиз из раздела [Releases](../../releases)
2. Распакуй архив
3. Запусти `DarkLedger.exe`

Установка не требуется — все зависимости вшиты в `.exe`.

## 🗂️ Где хранятся данные

%APPDATA%\DarkLedger
├── settings.json — настройки
├── Stats\ — статистика по дням (yyyy-MM-dd.json)
├── Notes\ — заметки Дневника (yyyy-MM-dd.txt)
├── Reports\ — сохранённые отчёты
└── Logs\ — логи сессий
